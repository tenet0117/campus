部署说明：
环境要求
JDK 17+
MySQL 8.0+
Redis 7.x（可选，用于缓存加速）
Node.js 20+
Maven 3.6+
1. 初始化数据库
# 执行建库脚本，会自动创建数据库、表和示例数据
mysql -u root -p < db/init.sql
数据库名 campus_trading，包含建表语句与示例数据。

2. 配置后端（环境变量 / Profile）
敏感配置已外置，不要把真实密钥提交进仓库。可复制根目录 .env.example 作为参考。

变量	说明	本地开发默认（dev profile）
SPRING_PROFILES_ACTIVE	激活环境	dev
DB_PASSWORD	MySQL 密码	123456
JWT_SECRET	JWT 密钥（≥32 字符）	仅开发用占位密钥
CORS_ORIGINS	允许的前端源	http://localhost:5173,5174
DEEPSEEK_API_KEY	AI 助手 Key	空
本地直接启动会加载 application-dev.yml；生产请使用：

export SPRING_PROFILES_ACTIVE=prod
export DB_URL=jdbc:mysql://...
export DB_USERNAME=...
export DB_PASSWORD=...
export JWT_SECRET=请使用强随机字符串至少32字符
export CORS_ORIGINS=https://your-frontend.example.com
3. 启动后端
cd campus-backend
mvn spring-boot:run
# 或指定端口
mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=8081
后端：http://localhost:8081/api/v1
开发环境 API 文档：http://localhost:8081/api/v1/swagger-ui.html（仅 dev / SWAGGER_ENABLED=true）

安全冒烟测试：

cd campus-backend
mvn -Dtest=SecuritySmokeTest test
4. 启动前端
cd campus-fonted
npm install
npm run dev -- --port 5173
浏览器打开：http://localhost:5173
前端工程脚本：npm run lint / npm run format / npm run build

文件存储（阿里云 OSS）
默认 FILE_STORAGE_TYPE=oss。Endpoint / Bucket 已写在配置里；密钥从本机环境变量读取：

ALIBABA_AIR_TEST1_ACCESSKEY_ID
ALIBABA_AIR_TEST1_ACCESSKEY_SECRET
默认：oss-cn-beijing.aliyuncs.com + Bucket java-oss-11。若 IDEA 读不到环境变量，重启 IDE 后再启动后端。

Bucket 需允许对应前缀的公有读（或设 OSS_SIGNED_URL=true 使用签名链接）。
临时切回本地：FILE_STORAGE_TYPE=local。

配置外置：application.yml + application-dev.yml / application-prod.yml，密钥走环境变量
安全：CORS 白名单、公开接口仅 GET 浏览、POST /products 需登录、统一 401/403 JSON
API：ApiResponse + 全局异常；分类/消息/AI/上传控制器去掉手写 Map 吞异常
订单：条件更新防超卖，WebSocket 通知事务提交后发送；结算页支持收货人/地址信息
前端：Element Plus + Pinia + meta 路由鉴权 + API 模块拆分 + 核心页组件化
管理后台：统一 Element Plus 列表页；用户头像 / 商品缩略图；用户·商品·订单详情弹窗；分类弹窗编辑
头像：种子用户 avatars/avatar0N.png 映射到前端 public/avatars 静态资源，上传头像走 OSS
